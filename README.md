# Rachit Pandey - Portfolio

My personal portfolio website built with **React**, **Tailwind CSS**, and **Vite**.

## Tech Stack

- React + Vite
- Tailwind CSS
- Framer Motion
- Lucide Icons

## Live Demo

[View Portfolio](https://your-portfolio-url.onrender.com)

## Sections

- Hero
- About
- Skills
- Projects (Spice Craft, Sprint Room, Portfolio, StartupConnect)
- Certifications
- Contact

## Run Locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

Output goes to `dist/` folder — ready for deployment on Render, Vercel, or Netlify.
